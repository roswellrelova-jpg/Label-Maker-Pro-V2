Label Maker Pro V4 — User Manual

Precision Area Mapping & Inventory System

Label Maker Pro V4 is a web-based operations tool for shipboard photography teams. It creates professional cabin delivery labels, tracks retail item sales, and logs every delivery — all in one place.

What it does

  • ▸Prints professional labels — cabin number, area code, retail items, and special instructions on every sticker
  • ▸Auto-assigns Area Codes — no need to remember which deck is which zone
  • ▸Tracks retail inventory — every item attached to a delivery is auto-deducted from stock
  • ▸Logs everything — full searchable history of all deliveries
  • ▸Tracks issues — reprint requests and print errors are flagged until resolved
ProblemSolution
Messy handwritten labelsClean printed stickers every time
No delivery recordsFull Log with timestamps, searchable
Lost track of stockInventory auto-deducts on every log
Wasted stickers from wrong start positionVisual grid lets you set exact print start

The app has 5 main tabs at the top. Each tab handles a specific part of your workflow.

SEARCH & LOG

Where you spend most of your time. Enter cabin numbers, attach retail items, and log deliveries.

PRINT QUEUE

Labels waiting to be printed. Set the sticker start position here, then hit Print Labels.

FULL LOG

Complete history of every delivery. Search, filter, and export to Excel.

INVENTORY

Your product catalog and stock tracker. Add items, update quantities, see what's running low.

REPRINTS & ISSUES

Log and resolve print errors, jams, or incorrect deliveries. A red banner flashes at the top until all issues are cleared.

Top-right controls

  • ▸Theme selector — Day, Night, Sepia, ROG, Legion, Razer, Alienware
  • ▸Lookup — opens your order management system in a new tab
  • ▸Help (this button) — opens this manual
  • ▸Settings ⚙️ — configure printer URL, area code ranges, label format

Go to Search & Log tab for every delivery. Follow these steps:

1
Enter the Cabin Number

Type the cabin number in the large center field. Accepts numbers and text like VIP, STAFF, etc.

2
Add Retail Items (optional)

Select from the Retail Items dropdown if the guest purchased a product. Set the quantity. Click "Add Another Retail Item" for multiple products.

3
Click LOG DELIVERY

The app auto-assigns an area code, adds a label to the Print Queue, and saves to the Full Log — all at once.

4
Print when ready

Switch to Print Queue, set your sticker start position, and click Print Labels.

✅Tip: Log several cabins first, then print all at once. Batching is faster than printing one at a time.
ℹ️Quick Log Search at the top of this tab lets you check if a cabin was already delivered today before logging again.

An Area Code is a number (e.g., 1, 2, 3…) that identifies which section of the ship a cabin belongs to. It prints large on every label so your team can sort deliveries by zone and walk an efficient route — instead of going back and forth across the entire ship.

What prints on the label

  • ▸AREA [number] — large and visible for sorting
  • ▸Cabin number — the guest's cabin
  • ▸Retail items — products included in the delivery
  • ▸Special instructions — added via the sticker grid
  • ▸Timestamp — when the delivery was logged

Setting up Area Codes

1

Click the Settings ⚙️ icon (top right)

2

Find the Area Mapping section and define cabin number ranges. Example: 10000–10399 = Area 1, 10400–10799 = Area 2.

3

Save. Every new delivery will now auto-assign the correct area code — no manual typing needed.

⚠️If a cabin number is outside your defined ranges, no area code will print. Make sure all cabin ranges are covered before the cruise starts.

The sticker sheet grid (right side of Search & Log tab) shows a visual map of your physical sticker sheet. Each cell = one sticker position. You tell the app where to start printing so you don't waste or overlap stickers from a partially used sheet.

1
Count used positions on your physical sheet

How many stickers at the beginning have already been peeled off?

2
Set the Skip count — or click the grid

Type the number in the Skipping field, or click any cell directly on the grid to set that as the start point.

3
Blue cells = will print. Gray = skipped.

The grid preview shows exactly what will happen on the sheet before you print.

4
Click a blue cell to add Special Instructions

Type notes like "Fragile", "Leave at door", or "VIP — Priority." These print on the label.

5
Click Print Labels

The QUEUE counter (blue box) shows how many labels are waiting. Check this before printing.

Retail items are products sold to guests alongside photos — frames, albums, packages, etc. Attaching them to a delivery does two things: prints the item on the label and auto-deducts from your inventory stock.

1

Enter the cabin number as normal.

2

Click the Retail Items dropdown — select the product the guest purchased. It shows the item name and category, e.g., Basic Gallery Frame (FRAMES).

3

Set the quantity in the field that appears.

4

Click "Add Another Retail Item" if more than one product was sold.

5

Click LOG DELIVERY. Items print on the label and are deducted from inventory.

ℹ️The dropdown order matches the sort order you set in the Inventory Manager table. Sort by Category to group similar products together in the dropdown.

The Inventory Manager tab is your product catalog. Set it up once and the system tracks stock automatically from that point on.

Sorting

Click any column header to sort. Click again to reverse. The retail dropdown in Search & Log mirrors this sort order automatically.

⚠️When restocking, enter the new total quantity — not the amount added. If you had 55 and received 20 more, type 75.

The Full Log tab is a complete timestamped record of every delivery logged. Nothing is deleted unless you choose to remove it.

Quick Log Search (Search & Log tab)

The search bar above the cabin field. Type a cabin, item name, or date. Results appear in a dropdown instantly. Click a result to prefill the cabin field.

Full Log Search Bar

Inside the Full Log tab. Searches the entire history. Best for audits, end-of-shift reviews, or finding a specific delivery.

Export to Excel

Use the Export button to download all log entries as a spreadsheet — for reports or sending to your photo manager.

Edit or Delete an Entry

Each row has action buttons. Edit to correct a mistake; delete if the entry was logged in error. Deleted entries are removed from inventory calculations too.

Use the Reprints & Issues tab when something goes wrong with a print job.

Common Reasons to Report

  • ▸Label printed in the wrong sticker position
  • ▸Wrong cabin number or item on the label
  • ▸Printer jammed and some labels were skipped
  • ▸Guest delivery was incorrect and needs a replacement
1

Click Report Issue (always visible in the top bar — no need to leave your current tab).

2

Enter the cabin number, describe the problem, and submit.

3

A red banner appears at the top of every screen until all issues are resolved.

4

After fixing it, go to Reprints & Issues and click Mark Resolved. The banner disappears when all are cleared.

✅Always clear all issues at the end of every shift. The red banner is your team's signal that something still needs attention.

Daily Workflow

STARTCheck Reprints & Issues — resolve anything from the previous shift first.
WORKLog deliveries in batches, then print all labels at once.
WORKAlways attach retail items at time of logging — not after the fact.
ENDExport Full Log to Excel. Check Inventory for yellow/red items and notify your manager.

Yellow — 5 units or fewer. Plan to reorder.
